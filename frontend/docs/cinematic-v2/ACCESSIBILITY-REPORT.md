# Accessibility Report

The implementation targets WCAG 2.2 AA. Verified behavior includes semantic landmarks, a first-focus
skip link, labelled navigation and drawer, Escape dismissal, visible focus styles, semantic chapter
content outside canvas, reduced-motion static mode, explicit animation control, meaningful SVG labels,
decorative media treatment, ≥44 px primary mobile controls and readable product content without WebGL.

Automated unit and Playwright checks passed. Manual screenshot review covered desktop, mobile drawer,
static reduced-motion content and ivory/dark scene contrast. Screen-reader testing with a named assistive
technology and 400% browser zoom remain deployment-stage manual checks; automated results alone are not
represented as full conformance certification.
