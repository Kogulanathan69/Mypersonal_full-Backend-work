# BuildMind BE Second Brain (Obsidian)

1. Unzip the archive, open **BuildMind-BE-Second-Brain** as an Obsidian vault.
2. Open [[00-HOME]] or [[SECOND-BRAIN-TREE]].
3. Open Obsidian Graph View to explore linked documents.
4. Use Search for terms like `Mapbox`, `FR-05`, `download`.
5. Optionally install/configure Obsidian Copilot separately; an API key or local model may be needed, and the plugin must be granted/index the appropriate documents before it can answer vault-wide questions.

**Avoid opening a parent directory containing both vaults** unless you deliberately want one combined vault.

The common source files are snapshots of the previously drafted BuildMind project documents. Source-code implementation has not been inspected. Do not infer deployed code, legally valid numerical rules, tested APIs or database physical tables from this package.
