# Templates

## ADR / scope change
- ID, date, requester, decision status, affected requirements and owners.
- Problem and options; selected decision and reason; rejected options.
- API/schema/data/security impact; migration compatibility; affected tests.
- Approval and implementation links; effective commit; supersedes ID.

## Task card
- Task ID / owner / branch / prerequisites.
- Current verified behavior, desired behavior, files and acceptance criteria.
- Test plan, edge cases, security, risk and out-of-scope.

## PR
- Task ID, linked ADR/contract, summary, files, migration and compatibility.
- Build/test commands + exact result; real vs fixture; limitations.
- Documentation updates, rollback guidance and security review; reviewers.

## Session handover
- Date, repository/branch/hash, owner/task ID, dirty files.
- Changes, tests/evidence, failed/skipped checks, blockers and next action.
- Explicit pending approval. Never include actual credential values.
